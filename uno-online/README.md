# Последняя карта

Онлайн-игра по правилам Уно для 2–10 игроков. Каждый играет со своего устройства
(телефон, планшет, компьютер) через обычную ссылку в браузере.

Сделано на **Node.js + Express + Socket.IO**. Сервер хранит все карты и проверяет
каждый ход, поэтому чужие карты нельзя подсмотреть.

```
uno-online/
├── server.js        — сервер: комнаты, подключения, таймеры ботов
├── game.js          — правила игры: колода, ходы, боты
├── package.json     — зависимости и команда запуска
└── public/          — то, что открывается в браузере
    ├── index.html
    ├── style.css
    └── client.js
```

---

## 1. Запуск на своём компьютере

1. Установите **Node.js** версии 18 или новее: https://nodejs.org (кнопка LTS).
2. Распакуйте архив и откройте папку `uno-online` в терминале
   (Windows: в папке нажмите на адресную строку, введите `cmd` и Enter).
3. Выполните:
   ```
   npm install
   npm start
   ```
4. Откройте в браузере **http://localhost:3000**.

### Игра по Wi-Fi без интернета
Если все в одной Wi-Fi сети, друзья могут подключиться к вашему компьютеру:
1. Узнайте IP компьютера: Windows — `ipconfig` (строка «IPv4-адрес»),
   macOS — Системные настройки → Wi-Fi → Подробнее.
2. На телефонах откройте `http://ВАШ_IP:3000`, например `http://192.168.1.15:3000`.
3. Если не открывается, разрешите Node.js в брандмауэре Windows.

## 2. Загрузка на GitHub

**Способ без командной строки:**
1. Зарегистрируйтесь на https://github.com.
2. Нажмите **+** справа вверху → **New repository**. Назовите, например,
   `uno-online`, выберите **Public** → **Create repository**.
3. На странице репозитория нажмите **uploading an existing file**.
4. Перетащите **содержимое** папки `uno-online` (файлы `server.js`, `game.js`,
   `package.json`, `README.md`, `.gitignore` и папку `public`).
   Папку `node_modules` загружать **не нужно**.
5. Нажмите **Commit changes**.

**Способ через Git** (если установлен https://git-scm.com):
```
cd uno-online
git init
git add .
git commit -m "Первая версия игры"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/uno-online.git
git push -u origin main
```

> GitHub Pages для этой игры **не подойдёт**: Pages показывает только
> статичные страницы, а игре нужен работающий сервер. Поэтому сервер
> запускаем на Render, а код берём прямо из GitHub.

## 3. Публикация в интернете (бесплатно, на Render)

1. Зайдите на https://render.com и войдите через **GitHub**.
2. **New +** → **Web Service** → выберите репозиторий `uno-online`.
3. Заполните:
   - **Language / Runtime:** Node
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Instance Type:** Free
4. Нажмите **Create Web Service** и подождите 2–3 минуты.
5. Вверху появится адрес вида **https://uno-online-xxxx.onrender.com**.
   Это и есть ссылка на игру: она открывается на любом устройстве.

Когда вы меняете код на GitHub, Render сам обновляет игру.

**Важно о бесплатном тарифе:** если в игру никто не заходил 15 минут,
сервер «засыпает». Первое открытие после этого занимает около минуты.
Просто подождите, дальше всё работает быстро. Комнаты при засыпании сбрасываются.

## 4. Как пригласить друзей

1. Откройте ссылку на игру, введите своё имя и нажмите **«Создать комнату»**.
2. Появится код комнаты из 4 символов (например `K7PX`) и кнопка **«Пригласить»**.
   Она копирует ссылку вида `https://…onrender.com/?room=K7PX`, а на телефоне
   сразу предлагает отправить её в WhatsApp, Telegram и т. д.
3. Друг открывает ссылку, вводит имя и нажимает **«Войти»**.
   Можно и иначе: открыть главную страницу и ввести код или выбрать комнату
   в списке «Открытые комнаты».
4. Когда все за столом, создатель комнаты (хост) нажимает **«Начать игру»**.
   Если игроков мало, хост может добавить ботов кнопкой **«+ Бот»**.

Пришедшие во время партии смотрят игру и садятся за стол в следующей.
Если кто-то отключился, за него через несколько секунд ходит бот. Обновив
страницу, игрок вернётся на своё место со своими картами.

## 5. Правила

- У каждого 7 карт. Ходят по кругу.
- Положите карту **того же цвета** или **того же числа/знака**, что верхняя карта сброса.
- **Пропуск ⊘** — следующий игрок пропускает ход.
- **Разворот ⇄** — направление меняется (вдвоём работает как пропуск).
- **+2** — следующий берёт 2 карты и пропускает ход.
- **Заказ цвета** — кладётся на любую карту, вы выбираете цвет.
- **+4** — заказ цвета, а следующий берёт 4 карты и пропускает ход.
- Нечем ходить — нажмите на колоду и возьмите карту. Если она подходит,
  её можно сразу сыграть, иначе ход переходит дальше.
- Когда кладёте **предпоследнюю** карту, нажмите **«Уно!»**. Забыли —
  любой соперник может нажать **«Поймать»**, и вы возьмёте 2 карты.
- Кто первым избавился от всех карт, выигрывает партию. Счёт побед виден за столом.

## Настройки

В начале `server.js` можно поменять:

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `BOT_DELAY` | 1300 мс | сколько «думает» бот |
| `OFFLINE_DELAY` | 8000 мс | через сколько бот ходит за отключившегося |
| `AFK_DELAY` | 60000 мс | автоход, если игрок в сети, но не ходит минуту |
| `ROOM_TTL` | 30 мин | когда удаляется пустая комната |

Порт задаётся переменной окружения `PORT` (по умолчанию 3000).
